Enterprise WMS

A warehouse management system for cold storage and FMCG warehouses, built by me alone. It runs on Cloudflare Workers with a D1 database and ships as one worker file plus one SQL schema, with no external dependencies.

  • FEFO and FIFO stock allocation
  • Admin and user roles, with each user limited to their own warehouse
  • Purchase orders, receiving, putaway, picking, packing and shipping
  • Barcode scanning with the phone camera
  • Audit logs, invoice profit accounting, and PDF and CSV export
